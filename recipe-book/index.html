连接 GitHub 菜谱仓库

数据会保存到你自己的 GitHub 仓库里，
所有访问者读写同一份数据。

如何获取 Token？
  1. GitHub → 头像 → Settings
  2. Developer settings → Personal access tokens
  3. 推荐 Fine-grained tokens，选择该仓库，权限勾选 Contents: Read and write
  4. 生成后复制粘贴到上方输入框
🔒 数据只存在你的 GitHub 仓库里
